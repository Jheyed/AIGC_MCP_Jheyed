# ADR-0002：MVP 采用已验证配方优先

- 状态：Accepted
- 日期：2026-10-18

## 背景

让 Agent 从零构建任意 ComfyUI 节点图自由度很高，但在模型、节点版本和显存条件不同的环境中难以稳定，也难以向初学者解释失败原因。

## 决策

MVP 以经过真实运行验证的工作流配方为主。Agent 选择配方并填写受控槽位，不默认从零构建复杂工作流。

## 理由

- 更容易验证和复现；
- 故障范围清晰；
- 能积累可复用的专业知识；
- 符合普通用户只表达创作目标的体验。

## 后果

- 初期能力范围取决于配方库；
- 新需求可能需要新增配方或模块；
- 后续可以逐步增加工作流组合与自动构建，但必须保留验证机制。

## 替代方案

允许 Agent 每次自由创建完整节点图。该方案暂时拒绝作为默认路径，但可以在未来作为实验性专家模式加入。

## 验证或复审条件

当自动构图具备可靠的节点兼容性检查、资源估算、沙箱测试和回滚能力后复审。
