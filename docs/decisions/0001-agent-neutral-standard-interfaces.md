# ADR-0001：采用多 Agent、标准接口优先的架构

- 状态：Accepted
- 日期：2026-10-18

## 背景

项目最初由 Codex 协助建立，但用户要求未来其他 AI Agent 能够顺畅接手开发和使用。

## 决策

核心能力使用公开、可移植的接口和文件格式。MCP 是主要 Agent 接口，同时保留 CLI 或等价程序接口用于测试和无 Agent 调用。Codex 专属配置只作为适配器存在。

## 理由

- 降低更换 Agent 的成本；
- 让核心能力可以独立测试；
- 避免项目退化成提示词集合；
- 使角色包、工作流和运行记录保持长期可用。

## 后果

- 每项核心能力需要与 Agent 适配层分离；
- 多 Agent 可用性必须通过实际客户端验证；
- 可能需要维护少量客户端配置，但这些配置不包含唯一业务逻辑。

## 替代方案

只为 Codex 编写 Skill 或 `AGENTS.md`。该方案开发更快，但无法满足根本要求，因此拒绝。

## 验证或复审条件

当 MCP 不再能被目标 Agent 普遍支持，或出现更开放且稳定的通用协议时复审。
